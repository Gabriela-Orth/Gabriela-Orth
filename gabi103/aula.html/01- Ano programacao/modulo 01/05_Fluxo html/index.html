O que é Conteúdo de Fluxo

* É a categoria principal que agrupa elementos que compõem o corpo de um documento HTML.

* Inclui praticamente todas as tags que aparecem dentro do elemento < body>.

* Serve para definir textos, listas, tabelas, formulários e estruturas genéricas.


Exemplos de Elementos de Fluxo

Texto e parágrafos: < p>, < a>, < span>.
Listas: < ul>, < ol>, < dl>.
Containers e seções: < div>, < section>, < article>.
Formulários: < form>, < input>, < button>.
Mídia: < img>, < video>, < audio>.
