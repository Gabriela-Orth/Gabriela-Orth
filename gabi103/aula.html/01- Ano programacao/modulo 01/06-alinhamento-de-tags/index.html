Formas de Alinhamento

Use style="text-align: left;" na tag ou elemento de bloco.

Centro: Use style="text-align: center;" para centralizar textos ou itens inline.

Direita: Use style="text-align: right;" para jogar o conteúdo para o canto direito.

Justificado: Use style="text-align: justify;" para alinhar as duas margens do parágrafo.
