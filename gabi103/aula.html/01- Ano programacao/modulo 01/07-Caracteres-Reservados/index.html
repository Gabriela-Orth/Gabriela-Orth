Caracteres Reservados no html

Principais Caracteres Reservados

Caracteres reservados no HTML são símbolos que possuem um significado especial de programação e precisam ser convertidos em entidades HTML para serem exibidos corretamente no navegador.


Se você usar estes símbolos diretamente no texto, o navegador pode achar que você está criando uma tag ou um código e gerar erros.
